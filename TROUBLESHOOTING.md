# Быстрое решение проблем

## Приложение не запускается

Откройте PowerShell в папке проекта и выполните:

```powershell
python --version
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Если `python` не найден, установите Python 3.11+ и включите **Add python.exe to PATH**.

## FFmpeg или ffprobe не найден

Проверьте:

```powershell
ffmpeg -version
ffprobe -version
```

Если команды не работают, установите FFmpeg по инструкции в README. Можно не менять `PATH`: укажите полные пути к доверенным `ffmpeg.exe` и `ffprobe.exe` из одной официальной сборки в боковой панели. Не выбирайте случайные EXE-файлы.

## Красная ошибка у имени кадра

Метка должна стоять в самом начале. Примеры:

```text
[0-05]_первый кадр.jpg
[1-02.250]_сцена.png
[00-01-05.750]_финал.webp
```

Секунды всегда записываются двумя цифрами от `00` до `59`. Метка — время **окончания**, начало вычисляется по предыдущему кадру.

## Кадр короче одного видеокадра

При 30 FPS один физический кадр длится примерно 33,3 мс. Увеличьте время окончания проблемного изображения или выберите 60 FPS. Приложение не пропускает такие интервалы автоматически, потому что это нарушило бы синхронизацию.

## Изображение повреждено или расширение подменено

Откройте файл в редакторе и пересохраните его в PNG, JPEG, WEBP или BMP с соответствующим расширением. Простого переименования `.jpg` в `.png` недостаточно.

## Аудио не читается

Пересохраните озвучку в WAV, MP3, M4A, AAC, OGG или FLAC. Убедитесь, что файл не пуст и содержит настоящий аудиопоток.

## Не хватает места

Интерфейс показывает оценку до запуска. Освободите указанный объём с запасом либо уменьшите разрешение, длительность или качество. Не удаляйте `temp` во время активного рендера.

## FFmpeg завершился с ошибкой

Интерфейс показывает безопасное краткое сообщение. Полный технический журнал находится в `logs/<ID-проекта>/ffmpeg.log`. Частые причины: нехватка места, запрет записи, повреждённый входной файл или файл результата, открытый другим приложением.

## Отмена долго завершается

После нажатия «Отменить рендеринг» дождитесь сообщения об отмене. Приложение сначала корректно завершает активный FFmpeg, затем очищает промежуточные клипы.

## Как безопасно закрыть приложение

1. Если идёт рендер, нажмите «Отменить» и дождитесь итогового статуса.
2. В окне PowerShell/CMD нажмите `Ctrl+C`.
3. После остановки сервера закройте окно браузера.

Готовые MP4 находятся в `output` и при очистке `temp` не удаляются.
